# ANL — Nations League das Américas

Projeto conceitual de identidade e experiência para uma competição continental de seleções das Américas, criado como case de portfólio.

## Visão

Construir uma Nations League das Américas com uma estética sul-americana contemporânea: popular, vibrante, expressiva e conectada à cultura do futebol do continente.

## Direção inicial

- Identidade visual e sistema de marca
- Formato da competição, ligas, grupos e calendário
- Comunicação de campanha e conteúdo para redes sociais
- Experiência digital, placares e elementos de transmissão
- Aplicações físicas, troféu e materiais de evento

## Referência visual

O estudo `americas-design-system.html`, fornecido pelo autor do projeto, será usado como ponto de partida para a direção de arte. As referências culturais devem ser tratadas com pesquisa e contexto, sem apresentar padrões inventados como pertencentes a povos específicos.
